# react-zustand-sandbox

Learning project. Practicing TDD (Vitest + React Testing Library) and
trying out Zustand — at work I mostly use Redux Toolkit, want to compare.

Stack: React 19, TypeScript, Vite, MUI v7.

Work in progress. Test setup and base layout are done, Zustand store
is next.

## Run

```bash
cd react-zustand-app
npm install
npm run dev
npm test
```
